# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately instead:
**Security → Report a vulnerability** in this repository
([direct link](https://github.com/dabo53ck/patchmon-hass/security/advisories/new)).
Include the version, what you found and how to reproduce it. Leave out real
tokens, server addresses and host names.

Once a fix is released, the advisory is published.

Vulnerabilities in PatchMon itself belong to the
[PatchMon project](https://github.com/PatchMon/PatchMon).
